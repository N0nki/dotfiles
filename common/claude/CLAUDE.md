# Global CLAUDE.md

## General

文章を記述するときは次のルールに従う。

- 英単語前後の半角スペースは作らない。
  - e.g. これはNG: 次の meeting に参加する。
- 丸括弧は半角を使う
- しつこく丸括弧で補足しないようにする。

## Commit messages

コミットメッセージを書くときは次のルールに従う。

- 英語の1行だけで書く。本文(body)は付けない
- 50 文字前後、命令形・小文字で始める(例: `add AGENTS.md`)。末尾にピリオドは付けない
- 「何を変えたか」を具体的に書く。`update` / `fix` / `wip` のような中身のないメッセージは使わない
- 1コミット1トピック。無関係な変更が混ざっていれば、コミットを分けることを先に提案する
- 生成物や個人環境ファイル(`~/.gitconfig.local` 等)はコミット対象にしない
- 候補提示などの詳細な手順は `commit-message` skill を使う

## Pull Requests

Pull Requestsを作るときは次のルールに従う。

- Pull Request Templateのフォーマットがあれば必ずそれに従う。
- だ・である調を使う。
